PROYECTO: SISTEMA DE GESTIÓN ACADÉMICA
======================================

## DESCRIPCIÓN:

Aplicación backend desarrollada para la gestión de un
sistema académico utilizando Node.js, Express y MySQL.

El sistema permite la autenticación de usuarios mediante
JWT y la gestión de información relacionada con usuarios,
actores académicos e inscripciones.

==================================================
TECNOLOGÍAS UTILIZADAS
======================

Backend:

* Node.js
* Express.js
* JavaScript (ES Modules)

Base de datos:

* MySQL
* XAMPP (Servidor MySQL)

Autenticación:

* JSON Web Token (JWT)
* bcrypt para encriptación de contraseñas

Pruebas de API:

* Thunder Client (extensión de Visual Studio Code)

==================================================
INSTALACIÓN DE DEPENDENCIAS
===========================

Ingresar a la carpeta backend:

npm install

Dependencias principales utilizadas:

npm install express
npm install mysql2
npm install cors
npm install bcrypt
npm install jsonwebtoken
npm install express-validator

==================================================
EJECUCIÓN DEL PROYECTO
======================

1. Iniciar el servidor MySQL mediante XAMPP.

2. Crear la base de datos PRUEBA.

3. Ejecutar el script SQL que contiene:

   * DDL (creación de tablas)
   * DML (datos de prueba)

4. Ubicarse dentro de la carpeta backend.

5. Ejecutar:

npm start

o

node app.js

El servidor iniciará en:

http://localhost:3001

==================================================
ENDPOINTS DISPONIBLES
=====================

1. LOGIN

---

POST:

/login

Permite autenticar usuarios y generar el token JWT.

Ejemplo Body:

{
"username":"erick.m",
"password":"123456"
}

Respuesta:

{
"token":"TOKEN_GENERADO"
}

==================================================

2. USUARIOS

---

Todas las rutas requieren autenticación mediante JWT.

GET:

/usuarios

Obtiene todos los usuarios.

GET:

/usuarios/:id

Obtiene un usuario específico.

POST:

/usuarios

Registra un nuevo usuario.

PATCH:

/usuarios/:id

Actualiza información del usuario.

DELETE:

/usuarios/:id

Elimina un usuario.

==================================================

3. ACTORES

---

Representa la generalización de PERSONA.

Incluye:

* Estudiantes
* Docentes
* Administrativos

GET:

/actores

Obtiene todos los actores registrados.

GET:

/actores/:id

Obtiene un actor específico.

==================================================

4. INSCRIPCIONES

---

Gestiona la matrícula académica.

GET:

/inscripciones

Obtiene todas las inscripciones.

GET:

/inscripciones/:id

Obtiene una inscripción con su detalle.

POST:

/inscripciones

Registra una nueva inscripción.

==================================================
AUTENTICACIÓN JWT
=================

Las rutas protegidas requieren enviar el token en
los Headers de la petición.

Header:

Authorization

Valor:

Bearer TOKEN_GENERADO

Ejemplo:

Authorization: Bearer eyJhbGciOiJIUzI1Ni...

==================================================
NOTAS IMPORTANTES
=================

* Ejecutar primero la base de datos antes de iniciar
  el backend.

* Verificar que MySQL esté ejecutándose en XAMPP.

* Las rutas protegidas no funcionarán sin un token JWT
  válido.

* El token tiene un tiempo de expiración definido en
  la configuración JWT.
